Проект «Widget for Recent Successful Bank Operations»
Виджет для личного кабинета клиента банка, отображающий последние успешные банковские операции пользователя. Основная задача — подготовка и фильтрация данных на бэкенде для UI.

Установка проекта
Клонирование репозитория:

bash
git clone https://github.com/Spectral82/Spctrl82
Инициализация виртуального окружения:

bash
python -m venv venv
Убедитесь, что Python добавлен в переменную PATH.

Активация окружения:

Для macOS и Linux:

bash
source venv/bin/activate
Для Windows:

bash
venv\Scripts\activate
Или используйте poetry shell (если установлен плагин poetry-plugin-shell).

Установка зависимостей:

Через requirements.txt:

bash
pip install -r requirements.txt
Через Poetry (для линтеров):

bash
poetry add --group lint flake8
# или
poetry add mypy

Модули проекта:

1. Модуль generators.py
Набор генераторов для работы с транзакциями и генерации номеров карт.

Функции:

filter_by_currency(transactions, currency_code)

Параметры:

transactions (list): список словарей с транзакциями.

currency_code (str): код валюты (например, "USD").

Возвращает: генератор транзакций с заданной валютой.

transaction_descriptions(transactions)

Параметр: transactions (list) — список словарей с транзакциями.

Возвращает: генератор описаний операций (строк).

card_number_generator(start, end)

Параметры:

start (int): начало диапазона (1–9999999999999999).

end (int): конец диапазона (≥ start, ≤ 9999999999999999).

Возвращает: генератор номеров карт в формате "XXXX XXXX XXXX XXXX".

2. Модуль decorators.py
Содержит декоратор log для логирования работы функций.

Особенности:

Логирование в файл или консоль.

Параметр filename (опционально): имя файла для логов. Если не задан, логи выводятся в консоль.

Запись ошибок: при исключении в лог попадает сообщение об ошибке и входные параметры функции.

Пример использования:

python
@log(filename="app.log")
def my_function():
    # код функции
    pass

3. Модуль masks.py
Функции для маскировки конфиденциальных данных.

Функции:

get_mask_card_number(card_number)

Параметр: card_number (str): полный номер карты.

Возвращает: замаскированный номер (например, "1234 56XX XXXX 7890").

get_mask_account(account_number)

Параметр: account_number (str): номер счёта.

Возвращает: замаскированный номер счёта (например, "***1234").

4. Модуль widget.py
Функции для работы с виджетами приложения.

Функция:

mask_account_card(info)

Параметр: info (str): строка с номером карты или счёта.

Возвращает: замаскированную строку. Автоматически определяет тип данных (карта/счёт) и применяет соответствующую маску.

5. Модуль processing.py
Функции для обработки данных транзакций.

Функция:

filter_by_state(transactions, state)

Параметры:

transactions (list): список словарей с транзакциями.

state (str): статус для фильтрации (например, "EXECUTED").

Возвращает: отфильтрованный список транзакций с заданным статусом.

Пример использования
python
from generators import filter_by_currency, transaction_descriptions
from masks import get_mask_card_number
from processing import filter_by_state

# Пример данных
transactions = [
    {"id": 1, "amount": 100, "currency": "USD", "description": "Покупка в магазине", "state": "EXECUTED"},
    {"id": 2, "amount": 50, "currency": "EUR", "description": "Перевод другу", "state": "PENDING"}
]

# Фильтрация по валюте
usd_transactions = list(filter_by_currency(transactions, "USD"))

# Получение описаний
descriptions = list(transaction_descriptions(usd_transactions))

# Маскировка номера карты
masked_card = get_mask_card_number("1234567890123456")

# Фильтрация по статусу
executed_transactions = filter_by_state(transactions, "EXECUTED")

## Функциональность модуля `data_reader.py`

В проекте создан отдельный модуль `data_reader.py`, реализующий функционал для чтения финансовых операций из файлов.

### Чтение данных из CSV

Реализована функция для считывания финансовых операций из CSV‑файла:

- принимает в качестве аргумента путь к файлу CSV;
- возвращает список словарей с транзакциями.

### Чтение данных из Excel

Реализована функция для считывания финансовых операций из Excel‑файла:

- принимает в качестве аргумента путь к файлу Excel;
- возвращает список словарей с транзакциями.

## Тестирование

Для новых функциональностей написаны тесты:

- тесты для функции чтения из CSV используют `Mock` и `patch`;
- тесты для функции чтения из Excel используют `Mock` и `patch`.

Тестирование
Проект покрыт тестами с использованием библиотеки pytest.

Запуск тестов:

Чтобы запустить тесты, выполните команду:

bash
pytest tests/
Покрытие тестами
Код проекта покрыт тестами более чем на 80 %, что обеспечивает его надёжность и стабильность.

Отчёты по покрытию:

Чтобы сгенерировать HTML‑отчёт по покрытию тестами:

Выполните команду:

bash
pytest --cov=.
Откройте отчёт в папке htmlcov — файл index.html в браузере.

Отчёт покажет:

процент покрытия кода тестами;

какие строки кода не покрыты тестами;

детализацию по файлам и функциям.
