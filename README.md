# Проект "Widget for Recent Successful Bank Operations"

## Описание:

Проект "Widget for Recent Successful Bank Operations" - это виджет для личного кабинета клиента крупного банка, 
показывающий несколько последних успешных банковских операций пользователя. Проект решает задачу подготовки и
фильтрации данных на бэкенде для дальнейшего отображения в пользовательском интерфейсе.

### **Установка:**

1. **Клонируйте проект** с этого репозитория, используя в PyCharm (в командной строке терминала) команду:
```
git clone https://github.com/Spectral82/Spctrl82
```
2. **Инициализируйте виртуальное окружение** командой:
```
python -m venv <название_окружения>
```
*Например:*
```
python -m venv venv
```
Однако важно убедиться, что у вас корректно настроен путь к Python в системной переменной `PATH`, чтобы команда работала без ошибок. О том, как добавить Python в PATH в Windows 11, смотри [здесь](https://ip-calculator.ru/blog/windows-11/how-to-add-python-to-path-on-windows-11-2/).
3. **Активируйте окружение** с помощью команды:
*   на macOS и Linux:
```
source venv/bin/activate
```
*   на Windows:
```
venv\Scripts\activate
```
*Или используйте `poetry shell` для активации виртуального окружения (доступно только при установленном плагине `poetry-plugin-shell`).*
4. **Установите все зависимости проекта** (указанные в файле `requirements.txt`) командой:
```
pip install -r requirements.txt
```
Также можно установить линтеры на выбор, используя Poetry с помощью команды:
```
poetry add --group lint <линтер>
```
Замените <линтер> на имя нужного линтера, например `flake8` или `mypy`, и они будут указаны в pyproject.toml. 
Если же использовать команду:
```
poetry add <линтер>
```
Тогда линтеры будут установлены для всего PyCharm

# Модуль generators

Модуль `generators.py` предоставляет набор генераторов для работы с финансовыми транзакциями и генерации номеров банковских карт.

## Доступные функции

### `filter_by_currency(transactions, currency_code)`

Генератор, фильтрующий транзакции по коду валюты.

**Параметры:**
* `transactions` (list): список словарей с транзакциями.
* `currency_code` (str): код валюты для фильтрации (например, `"USD"`).

**Возвращает:**
* Генератор (`yields`): транзакции, где валюта операции соответствует заданной.

### `transaction_descriptions(transactions)`

Генератор, возвращающий описания транзакций по очереди.

**Параметр:**
* `transactions` (list): список словарей с транзакциями.

**Возвращает:**
* Генератор (`yields`): описание операции в виде строки.

### `card_number_generator(start, end)`

Генератор номеров банковских карт в формате `XXXX XXXX XXXX XXXX`.

**Параметры:**
* `start` (int): начальное значение диапазона (от 1 до 9999999999999999).
* `end` (int): конечное значение диапазона (до 9999999999999999), должно быть >= `start`.

**Возвращает:**
* Генератор (`yields`): номер карты в формате `"XXXX XXXX XXXX XXXX"`.
